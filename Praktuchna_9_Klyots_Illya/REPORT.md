1. Що таке делегат у C#? Чим він схожий і чим відрізняється від вказівника на функцію?
Делегат — це типобезпечний об’єкт, який зберігає посилання на один або кілька методів з відповідною сигнатурою. Подібно до вказівника на функцію в C++, делегат дозволяє передавати методи як аргументи, проте на відміну від вказівника, делегат є об’єктом .NET, який перевіряє типи параметрів на етапі компіляції, що робить його безпечним для використання в керованому середовищі.

2. Різниця між делегатом та подією (event)
Делегат — це тип, який безпосередньо викликає методи, що на нього підписані. Подія (event) — це оболонка над делегатом, яка забезпечує інкапсуляцію: вона дозволяє зовнішнім об’єктам лише підписуватися (+=) або відписуватися (-=), але забороняє повну заміну списку підписників або прямий виклик події ззовні класу-видавця.

3. Приклади використання Action<>, Func<> та Predicate<>
Action: Використовувався для логування подій у консоль: Action<string> log = s => Console.WriteLine($"[LOG]: {s}");.
- Func<Student, double>: Застосовувався для генерації звітів та розрахунку середнього балу студентів.
- Predicate: Використовувався для фільтрації студентів у групі, наприклад: group.FindAll(s => s.AverageGrade < 60).

4. Як працює багатовіщальний (multicast) делегат? Де ви його застосовували?
Це делегат, внутрішній список викликів (invocation list) якого містить кілька методів. При виклику такого делегата всі методи виконуються послідовно. Я застосовував це в системі для одночасного логування змін у файл та оновлення інтерфейсу користувача при виникненні події StudentAdded.

5. Механізм лямбда-виразів та приклади
Лямбда-вираз — це компактна анонімна функція.
- students.OrderBy(s => s.Surname) — для сортування за прізвищем.
- students.Where(s => s.AverageGrade > 90) — для фільтрації відмінників.
- group.PerformOperation(s => s.SetDefaultGrade(0)) — для виконання масової операції над студентами.

6. Використання подій у системі
Події (StudentAdded, StudentRemoved, AverageGradeChanged) були інтегровані в класи StudentGroup та Student. Вони дозволяють системі автоматично реагувати на зміни даних: наприклад, при зниженні середнього балу спрацьовує подія, яка ініціює сповіщення викладача.

7. Труднощі роботи з делегатами
Основна складність полягала в керуванні часом життя об’єктів, оскільки підписка на подію може призвести до витоку пам’яті (об’єкт не видаляється, поки на нього є посилання в делегаті). Вирішив це шляхом обов'язкової відписки (-=) у деструкторах або при видаленні об'єкта з колекції.

8. Що нового ви дізналися?
